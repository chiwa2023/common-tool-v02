# コンポーネント設計書: InputPref.vue

## 1. 概要

- 都道府県コード（JIS/LGコードの上位2桁）を直接手入力、または都道府県一覧ドロップダウンリストから選択して指定・取得するためのコンポーネントです。
- コードをキーボードから直接テキスト入力できる（最大2桁）テキストボックスの他、都道府県名を選択できる1つのセレクトボックスを提供します。
- テキストボックスに都道府県コード（2桁）が手入力された際、自動的にドロップダウンセレクトボックスの選択状態を追随（連動）させます。
- 常に最新の都道府県コードおよび都道府県名称のデータを親コンポーネントへリアルタイムに同期します。

## 2. 依存子コンポーネント

- `MessageView.vue`（都道府県一覧非同期取得時のシステムエラー表示用）

## 4. インターフェース仕様

### Props

| プロパティ名 |    型    | 必須  |                                  説明                                  |
| :----------- | :------- | :---: | :--------------------------------------------------------------------- |
| `lgCode`     | `string` |  Yes  | 都道府県コード（または都道府県を含む地方公共団体コード）の初期設定値。 |

### Emits

|   イベント名   |                    引数                     |                                               説明                                                |
| :------------- | :------------------------------------------ | :------------------------------------------------------------------------------------------------ |
| `sendPrefCode` | `optionDto: SelectOptionStringDtoInterface` | 都道府県の指定・選択が更新された際、最新コード（`value`）と都道府県名称（`text`）を親に発信する。 |

## 5. データ構造 (DTO)

本コンポーネントで使用される主なインターフェースです。

### `SelectOptionStringDtoInterface` 仕様

| プロパティ名 |    型    |               説明                |
| :----------- | :------- | :-------------------------------- |
| `value`      | `string` | コード値（都道府県コード：2桁等） |
| `text`       | `string` | 名称（「東京都」等の都道府県名）  |

## 6. 処理ロジック (ライフサイクル & イベントハンドラ)

### 6.1 `watch(props)`

- **契機**：親コンポーネントから渡されるProps（特に `lgCode`）が更新された時
- **処理内容**：
  - 更新後のProps値をローカル変数 `lgCodeEdit.value` に上書き同期し、親とのバインド状態を最新に保ちます。

### 6.2 `onPrefSearch()` / `onClickPart()`

- **契機**：テキストボックスやセレクトボックスがクリック（`click`）された際
- **処理内容**：
  1. 都道府県オプション配列 `prefOptions.value` の長さが `1` 未満（未ロード）であるかを検証します。
  2. 未ロードの場合：
     - [トークン取得共通関数: getAuthorizedPromiseArea()](../../use_api/getAuthorizedPromiseArea.md) を呼び出して認証トークンを取得します。
     - トークン取得成功時、バックエンドAPI `/lgcode-pref/search` に対し、HTTP POST メソッドでリクエストを送信（`FrameworkCapsuleDto` を送信）します。
     - レスポンスデータを `prefOptions.value`（都道府県選択肢）に代入・バインドし、選択肢を初期化します。
     - APIアクセスに失敗した場合は、システムエラーメッセージ（「システム管理者にお問い合わせください」）を表示します。

### 6.3 `onChangePref()`

- **契機**：都道府県セレクトボックスの変更（`change`）イベント発生時
- **処理内容**：
  1. 直接入力値 `lgCodeEdit.value` を選択された都道府県コード `selectedPref.value` に同期します。
  2. 選択された都道府県オブジェクトを `prefOptions.value` から検索し、該当する都道府県名（`text`）を抽出します。
  3. 抽出結果を用い、イベント `sendPrefCode`（`doEmit()` 経由）を親に発信します。

### 6.4 `onDirectInput()`

- **契機**：テキストボックスへの直接入力（`input`）イベント発生時
- **処理内容**：
  - 手入力されたコード（2桁）に基づいて、ドロップダウンの選択位置を自動追随させます。
  1. **都道府県コードの解析・設定（ちょうど2文字入力時）**：
     - 入力されたコード `lgCodeEdit.value` がちょうど2文字である場合：
       - 現在入力されているコードが、現在選択中のセレクトボックス値 `selectedPref.value` と異なるかを検証します。
       - 異なる場合、かつ都道府県オプションリストに合致するコードが存在する場合：
         - 都道府県セレクトボックス `selectedPref.value` をその手入力されたコードに自動設定し、同期します。
         - 都道府県名を取得し、親へ通知するための文字列とします。
       - オプションリストに合致するコードが存在しない場合：
         - セレクトボックス `selectedPref.value` を空文字にクリアします。
  2. **データ同期（リアルタイム同期）**：
     - コードの妥当性にかかわらず、入力された瞬間の値（`lgCodeEdit.value`）を常に最新値として親とリアルタイム同期するため、`doEmit()` を呼んでイベントを送信します。

### 6.5 `doEmit(value, text)`

- **処理内容**：
  - 新規に `SelectOptionStringDto` オブジェクトをインスタンス化し、プロパティ `value` にコード、`text` に名称（都道府県名）を設定して親コンポーネントに対し `sendPrefCode` イベントとして送信します。
