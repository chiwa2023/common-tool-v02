# コンポーネント設計書: InputLgcode.vue

## 1. 概要

- 地方公共団体コード（JIS/LGコード。都道府県または市区町村コード）を直接入力、またはドロップダウンメニューの選択によって指定・取得するコンポーネントです。
- コードをキーボードから直接テキスト入力できる他、都道府県および市区町村を連動選択できる2つのセレクトボックスを提供します。
- コードの非同期取得を処理するバックエンドAPIの詳細は、[使用API設計書: lgcode-search 地方公共団体コード検索API](../../use_api/lgcodeSearch.md) を参照してください。
- 親コンポーネントから渡される `isDigit5` プロパティに基づいて、コード全体の桁数制限を「5桁チェックデジットなし」または「6桁チェックデジットあり」に動的に切り替えます。
- 都道府県の選択時に連動して該当都道府県配下の市区町村サジェストリストを非同期取得し、市区町村のセレクトボックスの選択肢を自動更新します。
- テキストボックスへの直接手入力時には、入力されたコードから都道府県（上位2桁）や市区町村コードを即座に解析し、セレクトボックスを自動で追随（連動）させ、常に親コンポーネントと最新コード・名称情報を同期します。

## 2. 依存子コンポーネント

- なし(メッセージ表示コンポーネントを除く)

## 4. インターフェース仕様

### Props

| プロパティ名 |    型     | 必須  |                                              説明                                              |
| :----------- | :-------- | :---: | :--------------------------------------------------------------------------------------------- |
| `isDigit5`   | `boolean` |  Yes  | コード長さを5桁チェックデジットなしに制限するか、6桁チェックデジットありにするかの制御フラグ。 |
| `lgCode`     | `string`  |  Yes  | 地方公共団体コードの初期データ。                                                               |

### Emits

|  イベント名  |                    引数                     |                                          説明                                           |
| :----------- | :------------------------------------------ | :-------------------------------------------------------------------------------------- |
| `sendLgCode` | `optionDto: SelectOptionStringDtoInterface` | 選択・入力が更新された際、最新コード（`value`）と地名テキスト（`text`）を親に発信する。 |

## 5. データ構造 (DTO)

本コンポーネントで使用される主なインターフェースです。

### `SelectOptionStringDtoInterface` 仕様

| プロパティ名 |    型    |                  説明                  |
| :----------- | :------- | :------------------------------------- |
| `value`      | `string` | コード値（都道府県コードやLGコード等） |
| `text`       | `string` | 名称（都道府県名や市区町村名等）       |

## 6. 処理ロジック (ライフサイクル & イベントハンドラ)

### 6.1 `watch(props)`

- **契機**：親コンポーネントから渡されるProps（特に `lgCode`）が更新された時
- **処理内容**：
  - 更新後のProps値をローカル変数 `lgCodeEdit.value` に上書き同期し、親とのバインド状態を最新に保ちます。

### 6.2 `onPrefSearch()` / `onClickPart()`

- **契機**：テキストボックスや各種セレクトボックスがクリック（`click`）された際
- **処理内容**：
  1. 都道府県オプション配列 `prefOptions.value` の長さが `1` 未満（未ロード）であるかを検証します。
  2. 未ロードの場合：
     - [トークン取得共通関数: getAuthorizedPromiseArea()](../../use_api/getAuthorizedPromiseArea.md) を呼び出して認証トークンを取得します。
     - トークン取得成功時、バックエンドAPI [都道府県一覧取得 API](../../use_api/lgcodeSearch.md) に対し、HTTP POST メソッドでリクエストを送信（`FrameworkCapsuleDto` を送信）します。
     - レスポンスデータを `prefOptions.value`（都道府県選択肢）に代入・バインドし、選択肢を初期化します。
     - APIアクセスに失敗した場合は、システムエラーメッセージ（「システム管理者にお問い合わせください」）を表示します。

### 6.3 `searchCity()`

- **契機**：都道府県選択時、または手入力により都道府県コード（上位2桁）が特定された時
- **処理内容**：
  1. [トークン取得共通関数: getAuthorizedPromiseArea()](../../use_api/getAuthorizedPromiseArea.md) からトークンを取得し、バックエンドAPI [市区町村検索 API](../../use_api/lgcodeSearch.md) に対し HTTP POST で市区町村検索リクエストを送信します。
  2. リクエストの条件（`SearchAllCityLgcodeCapsuleDtoInterface`）には、以下を設定します：
     - `isSearch5Digit` ← `props.isDigit5`
     - `lgCode` ← 選択された都道府県コード（`selectedPref.value`）
  3. レスポンスデータを市区町村のドロップダウン選択肢 `cityOptions.value` に代入・バインドします。
  4. 例外またはAPIエラー発生時は、エラーメッセージを表示します。

### 6.4 `onChangePref()`

- **契機**：都道府県セレクトボックスの変更（`change`）イベント発生時
- **処理内容**：
  1. 直接入力値 `lgCodeEdit.value` を選択された都道府県コード `selectedPref.value` に同期します。
  2. 選択された都道府県オブジェクトを `prefOptions.value` から検索し、該当する日本語テキスト（都道府県名）を抽出します。
  3. 抽出結果を用い、イベント `sendLgCode`（`doEmit()` 経由）を親に発信します。
  4. 選択された都道府県に対応する市区町村を非同期検索するため、`searchCity()` を呼び出します。

### 6.5 `onChangeCity()`

- **契機**：市区町村セレクトボックスの変更（`change`）イベント発生時
- **処理内容**：
  1. 直接入力値 `lgCodeEdit.value` を選択された市区町村コード `selectedCity.value` に同期します。
  2. 選択された市区町村オブジェクトを `cityOptions.value` から検索し、日本語テキスト（市区町村名）を抽出します。
  3. 抽出結果を用い、イベント `sendLgCode`（`doEmit()` 経由）を親に発信します。

### 6.6 `onDirectInput()`

- **契機**：テキストボックスへの直接入力（`input`）イベント発生時
- **処理内容**：
  - キーボード等から直接入力されたコードに基づいて、ドロップダウンの選択位置を自動追随させます。
  1. **都道府県部分の解析（2文字以上入力時）**：
     - 入力されたコードの上位2桁（都道府県コード部分）を抽出します。
     - 抽出したコードが現在選択されている都道府県コード `selectedPref.value` と異なる場合、かつ都道府県オプションリストに合致するコードが存在する場合：
       - `selectedPref.value` をその上位2桁コードに自動設定し、対応する市区町村候補リストを読み込むため `searchCity()` を非同期実行します。
  2. **市区町村コードの確定（最大文字数到達時）**：
     - 入力された `lgCodeEdit.value` の長さが `digitlgcode`（5桁又は6桁）に達した場合：
       - 市区町村オプションリスト `cityOptions.value` の中に合致するコードが存在するか検証します。
       - 存在する場合は、市区町村セレクトボックス `selectedCity.value` の選択を自動的に合わせます。
  3. **空文字入力時**：
     - 入力値が空の場合は、都道府県・市区町村のセレクトボックスの選択をすべて未選択（空文字）にリセットします。
  4. **データ同期（リアルタイム同期）**：
     - コードの妥当性（完全に一致したか否か）にかかわらず、入力された瞬間の値（`lgCodeEdit.value`）を常に最新値として親とリアルタイム同期するため、`doEmit()` を呼んでイベントを送信します。

### 6.7 `doEmit(value, text)`

- **処理内容**：
  - 新規に `SelectOptionStringDto` オブジェクトをインスタンス化し、プロパティ `value` にコード、`text` に名称（地名）を設定して親コンポーネントに対し `sendLgCode` イベントとして送信します。
