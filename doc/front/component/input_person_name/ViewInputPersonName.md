# 親コンポーネント設計書: ViewInputPersonName.vue

## 1. 概要

- 結合された個人姓名（漢字・かな）を読取専用フィールドで表示します。「編集」ボタンを押下することで、詳細入力を行うための `InputPersonName.vue` をモーダルダイアログとしてオーバーレイ表示します。
- 子コンポーネントからの編集決定・キャンセル通知を受け取り、データ同期およびダイアログの表示制御を行います。

## 2. 依存子コンポーネント

本機能は、呼び出し元画面に配置される「表示用親コンポーネント」と、モーダルダイアログとして動作する「編集用子コンポーネント」の親子構造で構成されています。

| コンポーネントファイル名 |                                                       役割                                                       |        備考        |
| :----------------------- | :--------------------------------------------------------------------------------------------------------------- | :----------------- |
| `InputPersonName.vue`    | 子コンポーネント。姓名（漢字・かな）の「姓」「ミドルネーム」「名」を個別にテキスト入力するフォームを提供します。 | モーダル形式で表示 |

## 4. インターフェース仕様

### Props

| プロパティ名 |              型               | 必須  |              説明              |
| :----------- | :---------------------------- | :---: | :----------------------------- |
| `editDto`    | `InputPersonNameDtoInterface` |  Yes  | 編集対象となる個人姓名データ。 |

### Emits

なし（親コンポーネントでデータを直接更新、または受け取った内容をPropsに同期するため、本コンポーネントから上位へのEmitはありません）

## 5. 処理ロジック (イベントハンドラ)

### 6.1 `onInputPersonName()`

- **契機**：「編集」ボタン押下時
- **処理内容**：
  1. `isInput.value` を `true` に設定し、編集モーダルを表示する。

### 6.2 `recieveCancelInputPersonName()`

- **契機**：子コンポーネントからの `sendCancelInputPersonName` イベント検知時
- **処理内容**：
  1. `isInput.value` を `false` に設定し、編集モーダルを非表示にする（データ変更は破棄される）。

### 6.3 `recieveInputPersonNameInterface(sendDto)`

- **契機**：子コンポーネントからの `sendInputPersonNameInterface` イベント検知時
- **引数**：`sendDto: InputPersonNameDtoInterface` (子コンポーネントで編集されたデータ)
- **処理内容**：
  1. Propsの直接変更を避けるため、引数 `sendDto` の各プロパティを、Props経由の `inputPersonNameDto.value` の各プロパティへ個別に代入（コピー）する。
  2. `isInput.value` を `false` に設定し、編集モーダルを非表示にする。
